In this tutorial, you'll create a skill that teaches an agent how to reliably count letter occurrences in a word — a task that LLMs are notoriously inconsistent at on their own. By the end, you'll have a working skill and an understanding of the basic structure of the format.

## Prerequisites

- [VS Code](https://code.visualstudio.com/) with [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)

<Note>
This tutorial uses VS Code, but Agent Skills are a cross-tool format. The same skill works in any compatible agent, including Claude Code and OpenAI Codex.
</Note>

## Create the skill

A skill is a folder containing a `SKILL.md` file. Create the following file in your project:

**`.agents/skills/count-letters/SKILL.md`**

````markdown
---
name: count-letters
description: >-
  Count how many times a specific letter appears in a word.
  Use when asked to count letter occurrences in a word.
---

## Counting letters

Use the `tr` command to count occurrences of a letter in a word:

```bash
echo "<word>" | tr -cd '<letter>' | wc -c
```

Replace `<word>` with the target word and `<letter>` with the letter to count.
````

That's it — one file, about 15 lines. Here's what each part does:

- **`name`** — A short identifier for the skill. Must match the folder name.
- **`description`** — Tells the agent when to use this skill. This is how the agent decides whether to activate it.
- **The body** — Instructions the agent follows when the skill activates. Here, it's a `tr` command that strips everything except the target letter and counts what remains.

## Try it out

1. Open your project in VS Code.
2. Open the Copilot Chat panel.
3. Select **Agent** mode from the mode dropdown at the top of the chat panel.
4. Ask: **"How many times does the letter r appear in strawberry?"**

The agent should activate the `count-letters` skill, run the `tr` command in the terminal, and return the correct answer: **3**.

<Tip>
Type `/skills` in Copilot Chat to verify your skill was discovered. If `count-letters` doesn't appear, check that the file is at `.agents/skills/count-letters/SKILL.md` relative to your project root.
</Tip>

## How it works

When you added the skill to your project, three things happened behind the scenes:

1. **Discovery** — When the chat session started, the agent scanned default skill directories and found your skill. It read only the `name` and `description`, just enough to know when the skill might be relevant.

2. **Activation** — When you asked about counting letters, the agent matched your question to the skill's description and loaded the full `SKILL.md` body into context.

3. **Execution** — The agent followed the instructions in the body, adapting the `tr` command to the specific word and letter in your question.

This three-stage process is called **progressive disclosure**. It lets an agent have access to many skills without loading all their instructions up front. For more detail, see [How skills work](/what-are-skills#how-skills-work).
